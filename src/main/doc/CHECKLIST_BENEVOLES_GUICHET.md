# Checklist bénévoles guichet - Ticketchess

## Avant ouverture
- [ ] Ouvrir le site et vérifier l'accès internet.
- [ ] Vérifier l'accès à **Mes tournois** et aux pages tournoi.
- [ ] Vérifier qu'au moins un tournoi est visible.
- [ ] Avoir un contact organisateur disponible.

## Inscription d'un joueur
- [ ] Ouvrir le bon tournoi.
- [ ] Vérifier que le statut permet l'inscription.
- [ ] Cliquer sur **S'inscrire**.
- [ ] Rechercher le joueur (nom / licence).
- [ ] Sélectionner la bonne ligne.
- [ ] Confirmer que le joueur apparaît ensuite dans **Mes tournois**.
- [ ] Annoncer le statut de paiement (payé / non payé).

## Désinscription
- [ ] Ouvrir **Mes tournois**.
- [ ] Vérifier l'identité du joueur.
- [ ] Cliquer sur **Se désinscrire**.
- [ ] Confirmer la fenêtre de validation.
- [ ] Vérifier que le joueur n'apparaît plus en actif.

## Paiement carte
- [ ] Vérifier que la section **Paiement** est visible.
- [ ] Cliquer sur **Payer par carte**.
- [ ] Attendre le retour de confirmation.
- [ ] Vérifier le statut **Payé**.

## Paiement virement
- [ ] Cliquer sur **Télécharger le RIB**.
- [ ] Donner la consigne : indiquer nom + numéro FFE dans le libellé.
- [ ] Informer que la validation peut être différée.

## Paiement sur place
- [ ] Vérifier la modalité acceptée (chèque / espèces).
- [ ] Enregistrer selon la procédure de l'organisation.

## Cas à escalader
- [ ] Bouton d'inscription absent alors que le tournoi devrait être ouvert.
- [ ] Joueur introuvable et création impossible.
- [ ] Paiement effectué mais statut non mis à jour après délai normal.
- [ ] Erreur technique récurrente sur la page.

## Traces minimales à noter
- [ ] Nom du tournoi
- [ ] Nom du joueur
- [ ] Heure de l'action
- [ ] Type d'action (inscription / désinscription / paiement)
- [ ] Résultat (ok / ko) et message affiché
