## Build local

1. Installez MkDocs :

   ```bash
   pip install mkdocs
   ```

2. Depuis le dossier src/main/doc, lancez :

   ```bash
   mkdocs serve
   ```

3. Ouvrez l URL affichee dans votre navigateur.

## Build statique

```bash
mkdocs build
```

Le site genere est dans le dossier site.
