# Liste de contrôle pour les bénévoles — Paiement & pointage

Cette liste de contrôle concerne le **jour J** : accueillir les joueurs sur place, enregistrer les paiements et le pointage dans l'écran **Paiement & pointage** de Ticket Chess.

> Il ne s'agit pas du parcours du joueur (**S'inscrire** ou **Mes tournois**). Les bénévoles utilisent l'écran dédié accessible depuis la page du tournoi (droits d'organisateur requis).

## Avant l'ouverture

- [ ] Ouvrir le site et vérifier la connexion à Internet.
- [ ] Se connecter avec un compte autorisé (menu **Admin** ou droits d'organisateur).
- [ ] Ouvrir la page du **bon tournoi**.
- [ ] Vérifier que le badge en haut de **Paiement & pointage** affiche **En ligne**. Dans le cas contraire, les actions sont conservées localement, puis synchronisées.
- [ ] Avoir un contact organisateur disponible.

## Ouvrir Paiement & pointage

- [ ] Sur la page du tournoi, ouvrir le menu **⋯**.
- [ ] Cliquer sur **Paiement & pointage**.
- [ ] Si la série comprend plusieurs tournois, sélectionner le bon tournoi dans la liste déroulante.

## Accueillir un joueur déjà inscrit en ligne

- [ ] Onglet **Joueurs** : rechercher le joueur (nom ou licence).
- [ ] Vérifier le **statut de paiement** (payé ou non payé).
- [ ] Si le **pointage** est activé pour ce tournoi, cocher **Présent** pour le joueur arrivé sur place.
- [ ] En cas de paiement sur place (chèque ou espèces), marquer **Payé** selon la procédure du club.
- [ ] Vérifier l'entrée dans l'onglet **Historique**.

## Joueur non inscrit en ligne

- [ ] Orienter le joueur vers **S'inscrire** sur la page du tournoi (ou l'aider à s'inscrire avec son compte).
- [ ] Une fois le joueur inscrit, revenir dans **Paiement & pointage** pour enregistrer le pointage et le paiement.

## Filtres utiles

- [ ] **Non pointés** — joueurs inscrits mais pas encore accueillis.
- [ ] **Non payés** — joueurs avec un montant restant dû.

## Annuler une erreur

- [ ] Onglet **Historique** → **Annuler** sur la dernière action incorrecte.

## Avant la synchronisation avec SharlyChess

- [ ] Si le **pointage** est activé : tous les joueurs présents doivent être **pointés** ici.
- [ ] Informer l'arbitre que seuls les joueurs pointés seront envoyés à SharlyChess.

Voir [Synchronisation SharlyChess](SYNCHRO_SHARLYCHESS.md).

## Cas à transmettre à l'organisateur

- [ ] Badge **Hors ligne** persistant malgré une connexion à Internet.
- [ ] Joueur introuvable après inscription.
- [ ] Paiement enregistré mais statut incorrect après resynchronisation.
- [ ] Erreur technique récurrente.

## Traces minimales à noter

- [ ] Nom du tournoi
- [ ] Nom du joueur
- [ ] Heure de l'action
- [ ] Type (pointage, paiement ou annulation)
- [ ] Résultat (succès ou échec) et message affiché
