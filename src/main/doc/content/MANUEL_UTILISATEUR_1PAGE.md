# Ticket Chess — Guide rapide (1 page)

**S'inscrire** — Ouvrir le tournoi → **S'inscrire** → rechercher le joueur (nom ou licence) → **+ Sélectionner** → vérifier le message de confirmation. Conditions : être connecté ; tournoi au statut **Inscriptions ouvertes** ; quota non atteint (ou file d'attente disponible).

**Se désinscrire** — **Mes tournois** → **Se désinscrire** → confirmer.

**Payer** — Section **Paiement** dans **Mes tournois** : **Payer par carte**, **Télécharger le RIB** (virement avec nom et numéro FFE) ou paiement sur place. Vérifier que le statut est **Payé**.

**File d'attente** — Si le tournoi est complet : s'inscrire malgré tout, puis suivre sa **position** dans **Mes tournois** → **Mes inscriptions en file d'attente**.

**S'inscrire au club** — Menu **S'inscrire au club** → sélectionner le joueur → choisir les options → confirmer ; suivre la demande dans **Mes adhésions au club**.

**Un problème ?** Si le bouton **S'inscrire** est absent, vérifier la connexion, le statut du tournoi et le quota. Si un virement n'est pas encore validé, attendre le délai de traitement, puis contacter l'organisation.
