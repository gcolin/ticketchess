# MkDocs pour la documentation

## Prerequis

- Python 3
- pip

## Installation

```bash
pip install mkdocs
```

## Lancer en local

Depuis src/main/doc :

```bash
mkdocs serve
```

## Generer le site

Depuis src/main/doc :

```bash
mkdocs build
```

Le site est genere dans src/main/doc/site.
